# Простой калькулятор на Python

Простой калькулятор для выполнения базовых арифметических операций через командную строку.

## Функциональность

- Сложение (+)
- Вычитание (-)
- Умножение (*)
- Деление (/)
- Поддержка работы с десятичными числами
- Проверка деления на ноль
- Два режима работы: через аргументы командной строки и интерактивный

## Требования

- Python 3.6 или выше

## Установка

1. Скачайте файл `Calc.py`
2. Убедитесь, что Python установлен на вашем компьютере

## Использование

### Способ 1: Через аргументы командной строки

```bash```
python calculator.py <число1> <операция> <число2>

### Способ 2: Через аргументы командной строки

python calculator.py

Затем следуйте инструкциям на экране. Для выхода введите exit в любом поле.
